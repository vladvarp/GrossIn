# ChrisoChat

Крысиный мессенджер без СМС и регистраций — один файл `index.html`, тёмный UI и чат через публичные серверы [ntfy](https://ntfy.sh).

## Как это работает

1. Вы вводите **ник** и **пароль норы**.
2. Пароль хешируется (SHA-256) в уникальный ID канала ntfy.
3. В нору попадают только те, кто знает пароль **и** заходит на **тот же** сервер.
4. История сообщений на стороне ntfy — около **12 часов**.

Регистрации нет: всё крутится в браузере, настройки и последние ники/норы хранятся в `localStorage`.

## Возможности

- Выбор публичного ntfy-сервера с пингом
- Генерация и вставка пароля норы
- Онлайн-статусы (presence) и список «кто в норе»
- Эмодзи-аватары и эмодзи-пикер
- Отправка фото (до 4 за раз; загрузка на временный хостинг, хранение ~72 ч)
- Цитаты ответов, очередь отправки с повтором при ошибке
- Адаптивная вёрстка под телефон и desktop

## Запуск

Сборка не нужна — достаточно открыть файл:

```bash
# вариант 1: просто открыть в браузере
index.html

# вариант 2: локальный сервер (удобнее для clipboard / некоторых API)
npx serve .
# или
python -m http.server 8080
```

Затем откройте страницу в браузере, выберите сервер, введите ник и пароль норы.

## Стек

| Часть | Технология |
|--------|------------|
| Клиент | Один HTML + CSS + vanilla JS |
| Транспорт | HTTP POST / poll к ntfy |
| Комнаты | SHA-256 от пароля → topic |
| Фото | Litterbox (catbox), запасной путь — imgbb |
| Хранение UI | `localStorage` |

## Приватность

- Пароль **не** уходит на сервер как есть — в topic попадает только хеш.
- Сообщения идут через выбранный публичный ntfy: оператор сервера теоретически видит содержимое топика.
- **Фото не приватны**: файл сначала попадает на публичный файлообменник; у кого есть ссылка — тот может открыть картинку. Не отправляйте то, что нельзя показывать посторонним.
